# Wear UI Laboratory

一个会随着真实操作留下使用痕迹的 UI 实验项目。按钮、拨片、滑杆、输入框、标签、导航、纸质卡片、选择控件、滚动条和旋钮，都采用与各自交互方式对应的磨损逻辑。

项目当前只用于本地访问，不包含线上站点关联，也不会自动保存上一次打开时的磨损状态。

## 本地启动

需要 Node.js 22.13 或更高版本。

```powershell
npm install
npm run dev
```

然后访问 `http://localhost:5173/`。开发服务已经启动时，也可以直接双击根目录的 `双击打开 Wear UI.html`。

## 检查构建

```powershell
npm run build
npm run lint
```

## 主要目录

- `app/`：展示页和全局视觉样式
- `components/wear/`：十个实验组件及其展示框架
- `hooks/use-wear-system.ts`：磨损数据、交互记录、复原和加速磨损逻辑
- `components/ui/`：基础交互组件
- `public/`：静态资源

## 磨损系统

每个组件拥有独立的使用次数、整体磨损、局部轨迹或字符位置磨损。对于存在多个局部磨损点的组件，右上角百分比表示当前最深的可见磨损相对于视觉上限的比例；Reset 按钮只复原当前组件，页面顶部可以复原全部组件或快速查看重度磨损。
